## 📖 Glossário de Sobrevivência

Se você se sente um pouco perdido com os nomes em inglês, não se preocupe! Até quem já estuda há tempo às vezes precisa de uma colinha. Aqui estão os termos que mais aparecem nos códigos:

* **Variável:** Um nome que guarda um valor. Pode ser qualquer coisa! Ex.: nome = "Pafúncia"
* **String (str):** É qualquer texto. Sempre fica entre aspas. Ex.: "Olá, Mundo!", 'Python é legal'
* **Integer (int):** Um número inteiro. Sem vírgula. Ex.: 10, -5, 2024
* **Float:** Um número com "ponto flutuante" (decimal). Em Python, usamos ponto, e não vírgula (se trocar pode dar um problemão!). Ex.: 10.50, 1.75
* **Input:** Comando para o usuário digitar algo. Ex.: nome = input("Seu nome:")
* **Print:** Comando para mostrar (imprimir) algo na tela. Ex.: print("Olá, Mundo!")
* **If/Else/Elif:** Tomada de decisão, onde "if" significa "se", "else" significa "senão" e "elif" é uma abreviação de "else if" (senão se). Ex.: if idade >= 987:
* **Loop (while/for):** Uma repetição. Faz o código rodar várias vezes. While significa "enquanto", e for significa "para", tipo "para cada item em uma lista". Ex.: for c in range(0, 10):
* **Boolean (bool):** Um valor lógico: Verdadeiro ou Falso. Ex.: True, False
* **List:** Uma lista de coisas guardadas juntas. Ex.: ['Maçã', 'Uva', 'Bergamota']
* **Dictionary (dict):** Uma coleção de dados com Rótulo e Valor. Ex.: {'nome': 'Pafúncia', 'idade': 987}

Quer uma dica? Estude inglês! A maioria dos recursos, tutoriais e documentações estão nesse idioma. Isso vai abrir muitas portas para você, tanto pra conseguir um emprego como pra ver aquela série que só tem em inglês!
