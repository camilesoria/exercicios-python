## 📂 O que você vai encontrar aqui?

No futuro, pretendo organizar tudo em pastas para ser fácil de entender:

* **Lógica Básica:** Exercícios de `print`, `input` e variáveis.
* **Estruturas de Controle:** `if`, `else`, `elif` (tomada de decisões).
* **Laços de Repetição:** `for` e `while`.
* **Funções:** Pequenos blocos de código reutilizáveis.

## 👩‍💻 Para Iniciantes (Como rodar os códigos)

Se você está começando agora, não tenha medo! Para testar meus códigos:

1.  Certifique-se de ter o [Python instalado](https://www.python.org/downloads/).
2.  Baixe este repositório ou copie o código do arquivo `.py`.
3.  No seu terminal, digite:
    ```bash
    python nome_do_arquivo.py
    ```
